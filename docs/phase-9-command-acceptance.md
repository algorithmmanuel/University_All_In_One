# Phase 9.5 - Cyber Command acceptance

The game catalogue is version 5 and contains thirty playable games: ten Cyber Explorers, ten Cyber Academy, and ten Cyber Command. Nine professional simulations were added with three defensive decision stages, server-owned scoring and finding keys. The new 2D professional workspaces display fictional evidence and role-specific case tools. The 3D scene remains a shared procedural room with per-game labels and accents, not nine custom 3D worlds.

The signed-in dashboard now displays game counts and direct pathway links. After pulling, restart FastAPI to load catalogue version 5. Run the backend suite with isolated PostgreSQL test settings, then frontend typecheck, tests and production build. Verify all ten professional games in 2D and 3D, inspect evidence, complete three stages and confirm saved scores and no duplicate awards. Validate cross-user access isolation and safe public mission responses before release.

This phase completes the planned catalogue, not public-launch readiness. Database migrations, end-to-end automation, accessibility, child safety, production monitoring and performance testing remain important work.
